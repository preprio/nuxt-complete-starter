# Add personalization to your Nuxt website

*Prepr CMS enables editors to create adaptive content directly in their content items to personalize elements of web pages.
This makes setting up personalization really simple and effective in increasing engagement and conversions.
This chapter of the Nuxt complete guide shows you how to set up personalization for the home page and track its metrics.*

At the end of this section, you'll see a personalized home page for visitors interested in electric cars.

![Personalized home page](https://assets-site.prepr.io/50el53oh29zt//personalized-home-page-electric-lease.png)

The steps below make use of the Adaptive content in the *Homepage* content item from the Acme Lease demo data.

## Set up personalization for the home page

You can show different personalized versions of the content to different groups (*Segments*) of visitors.
To show the right variant to the right visitor:

- Every visitor is given an ID that resolves to a segment they belong to.
- In your front end, you need to send this ID along with the query to retrieve the right variant.
- This is done by setting the value for the API request header, `Prepr-Customer-Id`, when you make the API request to retrieve the content.

You already [set the API request headers](/connecting-a-front-end-framework/nuxtjs/nuxt-complete-guide/step-4-add-ab-testing#set-the-api-request-headers) for A/B testing in the previous section.
The same headers tell Prepr which segment the visitor belongs to, so personalization works without any code changes.

<Steps>

### Add visitors to segments

For this setup we'll make use of the *Electric Car Lovers* segment in the Acme Lease demo data.
Make sure that the segment in your Prepr environment includes the condition, *Visitors who* `did` `view` `specific items`, `Electric Lease Landing Page`.

![electric car lovers segment](https://assets-site.prepr.io/6fefsntyp7zr//electric-car-buyers-segment.png)

If you need more details, check out the [Segments docs](/personalization/managing-segments).

You previously [enabled Prepr tracking](/connecting-a-front-end-framework/nuxtjs/nuxt-complete-guide/step-3-set-up-data-collection#enable-prepr-tracking) in your website.
This means a visitor gets added to the *Electric Car Lovers* segment whenever they view the *Electric Lease Landing Page* content item.

You can test this with the following steps:

1. Go to `http://localhost:3000/electric-lease` to open the electric lease landing page in your website.

        ![Electric Car landing page](https://assets-site.prepr.io/4fxqpaodooxg//acme-lease-electric-car-landing-page.png)

2. In your Prepr environment, go to the <FaUserGroup className="inline-icons"/> **Segments** page and click the **Electric Car Lovers** segment. You should see matching visitors in this segment like in the image below.

        ![Electric Car segment visitors](https://assets-site.prepr.io/6ar98qwvhmlo//electric-car-buyers-highlight-matching-visitors.png)

### Test your adaptive content

Now that people who visit the Electric lease landing page are being grouped into the *Electric Car Lovers* segment, you can test the adaptive content.
To test the adaptive content for the *Electric Car Lovers* segment follow the steps below.

1. Go to the Electric Car landing page in your website. For example: `http://localhost:3000/electric-lease`.

2. Wait a few seconds and go back to the home page. You can now see the personalized home page like in the image below.

![Personalized home page](https://assets-site.prepr.io/50el53oh29zt//personalized-home-page-electric-lease.png)

To see the non-personalized page, you can reset the cookies and refresh the page as follows:

1. Right-click the page to **Inspect the page**, click the **Application** tab. Under the cookies, click your localhost. You'll notice the `__prepr_uid` cookie in the list.

2. Right-click the localhost entry to **Clear** the cookies and refresh the page. You should now see the non-personalized content in the home page.

        ![clear cookies](https://assets-site.prepr.io/3naav2tjzw12//clear-cookies-for-personalization.png)

### Track impressions and conversion events

Your personalization is running successfully.
To see metrics for the adaptive content, the *Hero* section needs the same HTML attributes you added for the A/B test.
You can see the <FaCircleInfo className="inline-icons" /> **Awaiting data** message at the top of the Adaptive content block in the *Homepage* content item until the first impressions come in.

![Home page content item](https://assets-site.prepr.io/2b1r1jpzwdl1//acme-lease-homepage-adaptive-content-awaiting-data.png)

You already added the `data-prepr-variant-key` and `data-prepr-variant-event` attributes to the *Hero* section in the [previous section](/connecting-a-front-end-framework/nuxtjs/nuxt-complete-guide/step-4-add-ab-testing#add-html-attributes-to-track-impressions-and-conversion-events).
The tracking pixel records an impression when the *Hero* element scrolls into view and a click when the visitor clicks the link, for A/B tests and adaptive content alike.

<Callout type="info">
If you want to track a conversion other than a click event, e.g. a quote request, then set your `data-prepr-variant-event` to the custom event.
For example: `data-prepr-variant-event="QuoteRequest"`.
Check out the [Personalization doc for more details](/personalization/setting-up-personalization#track-impressions-and-conversions).
</Callout>

1. To start recording metrics, go to the home page in your website, click the **Find your car** button.

2. Now when you view the adaptive content in your *Homepage* content item, you can click the **Metrics** link and see the number of impressions and clicks like in the image below.

![Adaptive content metrics](https://assets-site.prepr.io/6j0q5cpmiu7e//home-page-adaptive-content-metrics-example.png)

</Steps>

Congratulations! You have successfully set up personalization with metrics in your Nuxt website.
Now, you can [install the Prepr preview toolbar](/connecting-a-front-end-framework/nuxtjs/nuxt-complete-guide/step-6-install-the-preview-bar) to switch between segments and A/B variants while you preview your website.
