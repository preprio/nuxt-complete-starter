## Create a Nuxt website with static components

If you have an existing Nuxt project then you can skip this section and continue with the next section to [make your Nuxt project dynamic with Prepr content](/connecting-a-front-end-framework/nuxtjs/nuxt-complete-guide/step-2-make-the-project-dynamic).
Otherwise, let's get started.

 <Steps>

### Install a Nuxt project

1. Open a terminal, go to your development projects folder and execute the command below to create a new Nuxt project called `nuxt-complete-starter` from the minimal template.

        ```bash copy
        npm create nuxt@latest nuxt-complete-starter -- --template minimal
        ```

        Choose `npm` as the package manager and skip the official modules for now. You'll add the module you need in the next section.

        ![TODO-SCREENSHOT: options when installing Nuxt](NEW)

2. When the project is successfully created, go to the `nuxt-complete-starter` folder, the root directory of the project, and run the project with the following commands in the terminal:

        ```bash copy
        cd nuxt-complete-starter
        ```

        ```bash copy
        npm run dev
        ```

3. You should now be able to view your app on your localhost, for example, `http://localhost:3000/`.

4. Open the Nuxt project with your preferred code editor.

<Callout type="info">
Nuxt 4 keeps your application code in the `app` folder.
All the files you create in this guide go in `app`, except for the configuration files in the project root and the server middleware in `server`, which you'll add in step 3.
</Callout>

5. Replace the code in the `app/app.vue` file with the following code to display your home page:

        ```vue filename="./app/app.vue" copy
        <template>
          <h1>My home page</h1>
        </template>
        ```

You should now see something like the image below on your localhost.

![TODO-SCREENSHOT: Empty Nuxt site](https://assets-site.prepr.io/zzx9ppdm4w7//nuxt-empty-home-page.png)

### Install Tailwind CSS and Nuxt Fonts

Follow the steps below to set up Tailwind styling and the Ubuntu font used by the Acme Lease website.

1. In the terminal, stop the server you started in the above step (`CTRL-C`) and install Tailwind CSS to make styling easier in the components you'll create below.

        ```bash copy
        npm install tailwindcss @tailwindcss/vite
        ```

2. Add the [Nuxt Fonts](https://fonts.nuxt.com/) module. It downloads the fonts you use in your CSS and serves them from your own website.

        ```bash copy
        npx nuxt module add fonts
        ```

3. Create an `app/assets/css/main.css` file to import Tailwind CSS and to set up the font and some additional colors and spacing:

        ```css filename="./app/assets/css/main.css" copy
        @import "tailwindcss";

        @theme {
          --font-sans: "Ubuntu", sans-serif;

          --text-mb-4xl: 2rem;
          --text-mb-5xl: 2.675rem;

          --spacing-8xl: 90rem;
          --container-8xl: 90rem;
          --container-prose: 50rem;

          --color-gray-50: #EEEEEE;

          --color-primary-50: #EFF6FF;
          --color-primary-100: #DBEAFE;
          --color-primary-600: #2563EB;
          --color-primary-700: #1D4ED8;

          --color-secondary-500: #64748B;
          --color-secondary-700: #334155;
        }

        /* Horizontal page gutter for section containers, matching the Acme Lease demo site. */
        @utility p-spacing {
          @apply px-4 sm:px-6 lg:px-8 xl:px-18 2xl:px-20;
        }
        ```

        The `p-spacing` utility gives every section the same horizontal page gutter, which grows with the screen width.
        Nuxt Fonts finds the `Ubuntu` font in `--font-sans` and downloads it for you.

4. Replace the code in `nuxt.config.ts` to add the Tailwind CSS plugin, your new `main.css` file and the font weights you need.

        ```ts filename="./nuxt.config.ts" copy
        import tailwindcss from '@tailwindcss/vite'

        // https://nuxt.com/docs/api/configuration/nuxt-config
        export default defineNuxtConfig({
          compatibilityDate: '2025-07-15',
          devtools: { enabled: true },
          modules: ['@nuxt/fonts'],
          css: ['~/assets/css/main.css'],
          // @nuxt/fonts finds the Ubuntu font in main.css and self-hosts it.
          fonts: {
            defaults: { weights: [400, 700] },
          },
          vite: {
            plugins: [tailwindcss()],
          },
        })
        ```

5. Test that Tailwind is correctly installed by updating the `app/app.vue` file as follows:

        ```vue filename="./app/app.vue" copy
        <template>
          <NuxtRouteAnnouncer />
          <h1 class="text-3xl font-bold underline">My home page</h1>
        </template>
        ```

6. Restart the localhost with `npm run dev`. You should see the updated styling like in the image below:

        ![TODO-SCREENSHOT: Nuxt empty site - updated styling](https://assets-site.prepr.io/2nk1omhmhiz1//nuxt-empty-home-page-updated-styling.png)
